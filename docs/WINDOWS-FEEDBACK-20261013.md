# Проверка Windows: замечания пользователя13.10.2026

Источник: сообщения пользователя после проверки новой сборки. Точный run/commit и первичные журналы пока не предоставлены. Это пользовательское наблюдение, не новый локальный native опыт. Проценты этапов не повышены.

Подтверждено пользователем: подготовка и вход; переключение и стрельба; инвентарь, установка модулей; перенос модулей/патронов в инвентарь; зоны, таймеры и эвакуация.

Открытые дефекты:

1. LOOK03/LOOK04: выбор персонажа визуально применяется после смены оружейного скина/перебора модулей меню. Выбор Default и одевание/сохранение дают warning1. Немедленное обновление/сохранение на Windows не подтверждено. Возможны разные причины; общий текст warning1 не идентифицирует opcode.
2. KIT01/KIT04: после выбора кирок T ведёт себя как со сноубордом, затем реагируетF. Требуется сопоставить winter_selection сwinter_kit_initialized иactualequipment11; исключить старую маску способности без угадывания enum.
3. INV06: перетаскивание оружия с земли в equipment не работает, правыйклик работает. Перенос модулей/патронов работает. Не приравнивать pickup и3E80междуequipmentслотами.
4. Стартовый набор: пользователь ожидает базовое оружие комплекта (пистолеты/дробовик), видит патроны. Предложенная команда явно задавалаWeaponProfilem4. Вwinter_selection_2022.py selected_fixture меняет только способность; стартовоеоружие остаётсяfixture. Полная исходнаякомплектация ещё нужна поInitItem ивыбраннымпакетам.
5. Мишень не найдена: предыдущая команда не содержала-Target, defaultnone. Это ошибка инструкции проверки; для отдельного опыта нужен-Targetplain. Положение относительно выбраннойклетки также требуетсяучитывать.
