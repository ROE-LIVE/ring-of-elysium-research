# Проверка Windows после работ 15 октября 2026

Цель — проверить текущую сборку на вашем ПК. Проверки Proton уже пройдены; результат Windows заполняется вами. Основной прогон занимает около 10–15 минут. Два других стартовых набора проверяются отдельными короткими запусками.

## Подготовка и основной запуск

В PowerShell из папки репозитория:

```powershell
git pull --ff-only
git rev-parse --short HEAD
.\run-roe-2022.cmd -Kit glider -Mode cycle -Duration 900 -ReliableUDP -IdleHandoff -WinterDoors -WinterWindows -DebugConsole -Target armored -LootCatalog .\config\windows-smoke-20261015.json
```

Клиент по умолчанию: `G:\REsearch\Ring of Elysium-2022`. Дождитесь готовности лаунчера, войдите через Training. В подготовке выберите планер. **В этом запуске оставьте клетку появления по умолчанию**, чтобы рядом оказался проверочный лут.

Windows-профиль `cycle` сейчас ускорен: шесть стадий длятся примерно 18/42/30/24/21/54 секунды, весь календарь — около 3:09 после появления. Аирдроп появляется примерно через 1 минуту, трос вертолёта — примерно через 2:08; проверять посадку надёжнее после окончания календаря. `Duration 900` ограничивает длительность запуска и не растягивает календарь. Отдельные исследовательские прогоны исходного 32-минутного сценария не являются этим быстрым профилем.

Каталог `windows-smoke-20261015.json` добавляет рядом со стартом M4, AK47, по 60 патронов 5.56/7.62, 30 патронов 9 мм, 10 патронов 12ga, жилет и шлем. Это фиксированная тестовая раскладка. В списке могут находиться и обычные предметы сцены. Ищите предмет по названию, поскольку после подбора ячейки списка сдвигаются.

В `runs\НОМЕР\launch-summary.json` ожидаются `launcher_revision: 20261015-starter-v1`, `weapon_slots: 3`, `source_hashes` и включённый custom loot catalog. Запишите номер папки запуска и commit из второй команды.

Для W15-19 откройте `runs\НОМЕР\client-debug-command.txt`, скопируйте напечатанную команду. В игре нажмите Enter, вставьте команду и нажмите Enter. Для второго снимка повторите. Если консоль не открывается, просто отметьте `SKIP`.

**Известная особенность финальной карты:** число около 0:53 в быстром профиле может перестать меняться после последней стадии; в исследовательском 32-минутном профиле наблюдалось 8:59. Первичный Lua оставляет старое число в кеше, тогда как серверный календарь продолжается. Запишите, продолжились ли закрытие областей и эвакуация; одно застывшее число не считать остановкой матча. Полёт/награды, баланс урона и размещение лута обслуживаются нашей реконструкцией.

Если задержка появилась, запишите время, сколько кликов потребовалось и номер run; новый журнал сохраняет поля отклонённого запроса. Ваш результат: ______.

## Что передать с отчётом

Сохраните заполненную копию этого файла. Для каждого запуска укажите номер папки `runs\...`, commit, выбранный комплект и результаты ID. При ошибке приложите снимок с инвентарём/магазином и примерное время.

Нужны `launch-summary.json`, `scene\events.jsonl` и, если делали снимки, `client-state.tsv`; при ошибке запуска также `build.log`/`endpoint.log` и текст из консоли. `scene\events.jsonl` не переименовывайте. Можно передать привычным способом папку run. `runtime`, `private`, полный клиент и сырые пакетные файлы для первичного разбора не требуются. Повторные обрывы localhost в этой серии проверялись собственным fault proxy под Proton; отключение интернета на Windows этот тест не заменяет.
