# BOT02 — конечный боезапас и диагностический LOS, 12.10.2026

Билд2022 x64 0.2.989.0/map16010; SHA256 EXE `2dca9b1e122e21363e14eeeb2372598c773205a907ed8d2b2d54a7229ad6ba18`. Стенд: независимая runtime-копия, Proton GE11-7, loopback namespace. Это собственный простой AI, не выгруженная серверная логика ROE.

## Реализация

Опциональный `attack_ammunition: {"magazine":2,"reserve":1}` ограничивает проверенную Citori10402. Вместимость2 и пустая перезарядка минимум2.130с взяты из уже проверенного WeaponState/RELOAD_TIMES и ресурсов; завершение происходит на следующем poll после deadline. При нуле магазина с запасом начинается перезарядка; без запаса огонь останавливается. Инвариант initial=magazine+reserve+spent сохраняется. Смерть отменяет pending reload/fire-stop/armor-repeat.

При `collision_boxes` проверяем отрезок actorXYZ+150Z→playerXYZ+120Z до расхода патрона и урона. Empty list означает диагностически открытый луч. None сохраняет совместимость старого дистанционного профиля. Преграды — ручные AABB, не исходная карта; конечные XYZ, радиус, delay/interval и защищённая/мёртвая цель проверяются до атаки. Endpoint связывает accepted attack→расход собственной брони→HP и сохраняет актуальный validation в журнале.
