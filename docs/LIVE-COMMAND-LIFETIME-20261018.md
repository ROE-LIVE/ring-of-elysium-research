# Одноразовые live-команды между матчами — 18.10.2026

По контракту ID команды подтверждается после её обработки. Ранее `LiveSceneCommands.sent` принадлежал экземпляру читателя; `finish_gameplay` удалял читатель, и новая сессия могла заново выдать те же ID из сохранившегося файла. Модель старого поведения воспроизводится в `037-gun05/20261018T0920-target-roster/live-id-lifetime-before.json`. Это доказательство жизненного цикла читателя; оно само по себе не доказывает повреждение NPC в настоящем повторном матче: ранняя команда могла быть отклонена ещё до создания мира.

Endpoint теперь хранит множество подтверждённыхID по actorUID на время жизни процесса. Новая сессия получает новый читатель с тем же множеством; другой actor имеет независимое множество. Содержимое/подпись файла перечитываются, поэтому новый ID принимается. Перезапуск эмулятора начинает новый журналID. Не сохраняем команды/ID в аккаунтный профиль.

`tests/test_live_scene_probe_2022.py::test_acknowledged_ids_survive_new_match_for_same_actor_only` проверяет finish/new state/старыйID/newID/otheractor. Для повторения ручного действия используйте новый `--id`, даже после нового Training. `--npc-uid 0x2040000800007` адресует отдельного NPC; без него остаётся первая мишень. Поле разрешено только для damage_npc; неизвестный/мёртвыйUID не получает урон.

Native006: после реальногоF/geton/эвакуации/Stats выполнены ReturnLobby→второйTraining. В новом матче снова10NPC сHP1000; старая команда не повторилась. ПослеC2SUDP20s snapshot подтверждает всеHP1000, новая команда с новымID меняет только NPC7→HP300. Первичные `037-gun05/20261018T0920-target-roster/native006-repeat-match.json`, `repeat006-continue.log`; Stats первого матчаKill0/Rescued1. Ошибка первого UI-helper: F повторялась раньше завершения6-секундного подъёма; помощник исправлен и подъём завершён обычным вводом. Предыдущая попытка после Native005 недействительна: UI был закрыт внешним timeout1800 прежде клика ReturnLobby, это не отказ клиента перейти в лобби.

Пример из второго PowerShell (подставить папку текущего запуска, она выведена launcher):

```powershell
.\.tools\python\python.exe -B .\tools\scene_action_2022.py --run "runs\CURRENT_RUN" --action damage_npc --damage 100 --npc-uid 0x2040000800007
```

Без `--id` инструмент создаёт новый уникальныйID автоматически. Путь Python должен соответствовать установленному bootstrap; `python` можно использовать, если он доступен в PATH. Проверять `live_state_action.accepted` и HP в отчёте, а не только сообщение «Добавлено».
