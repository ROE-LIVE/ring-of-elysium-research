## Linux

Нужны Python3.11+, .NET8 SDK, зависимости `requirements.txt`, существующий SSH server и обычная учётная запись Linux. Из корня клона:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
dotnet build server/lobby/LobbyEmulator.Sdk/LobbyEmulator.Sdk.csproj -c Release
.venv/bin/python -B tools/windows_launch.py --services-only --lan-tunnel --dotnet "$(command -v dotnet)" --profile default --duration 7200 --reliable-udp --idle-handoff
```

Walk не требует полной игры на Linux. Для cycle нужен один проверенный ресурс `runtime/regions-iceland-fast.dat`. На ПК с клиентом его можно получить без копирования всей игры:

```powershell
.
un-roe-2022.cmd -VerifyOnly -Mode cycle
```

Передать DAT в `runtime/` Linux-клона; launcher проверит SHA. Либо Linux `--client` может указывать на клиентские ресурсы2022. Настройки матча задаются на Linux: например `--mode cycle --weapon-profile m4 --kit snowboard`. Боевой профиль, зоны, боты и LiveControl принадлежат серверной части.

Сервисы и sshd должны находиться в одном host/network namespace: loopback Jupyter pod не равен loopback Linux-узла. В текущем ноутбуке SSH client есть, daemon отсутствует; этот стенд заменял SSH своими Unix forwarders. Сам по себе запуск peer в pod не делает его доступным через SSH узла.

## Windows11 — следующий обязательный контроль

OpenSSH Client должен быть установлен. Получить репозиторий и выполнить:

```powershell
git pull --ff-only
.
un-roe-2022.cmd -RemotePeer jovyan@192.168.1.25 -Profile default
```

Перед запуском игры отдельно проверить обычный вход `ssh jovyan@192.168.1.25` и выйти. Это не занимает игровой сеанс. Заменить `jovyan` своим SSH login, если он другой. Профиль Linux и Windows должен совпадать. Обычная SSH-авторизация и проверка host key; launcher не отключает их. SSH переносит TCP8001 и TCP19001; локальный UDP18001 соединяет игру с мостом. Игровые порты на LAN не открываются. .NET нужен Linux, удалённый Windows-клиент его не устанавливает. Игра по умолчанию `G:\REsearch\Ring of Elysium-2022`; существующая независимая runtime-копия используется повторно. Первый игровой запуск требует её создания.

Выбрать Training. Сохранить журналы обеих сторон: вход, выбор клетки/комплекта, лут, fire/reload, возврат и повторный Training. Закрыть игру/Ctrl+C — собственные процессы завершаются.
