# Проверка Windows2022 после отчёта15октября

Проверяем изменения поверх ваших успешных W15-01..08/11..18. Второй некорректный запуск не учитываем. Видео третьего подтверждает Kill1/Rescued1,359м,03:22. По первому/третьему пока получены текст и9.67с видео; журналы новой пары отдельно нужны для причины HP.

Изменения: учебный невидимый прямоугольник5HP/s выключен в обычном цикле; отдельный `-DiagnosticHazard` возвращает его. Закрытые чёрные регионы по-прежнему опасны. `-CycleScale 3` растягивает календарь зон, дропа и эвакуации вместе; выбор клетки, intro, reload, скорость транспорта и частота урона не замедляются. Это наш масштабированный пресет, а не исходный полноценный матч.

1. Закройте прошлую игру и её окно запуска. Откройте PowerShell в `G:\REsearch\run_roe_2022` либо в вашей папке этого репозитория.
2. Обновите и запустите:

```powershell
git pull --ff-only
git rev-parse --short HEAD
.\run-roe-2022.cmd -Kit glider -Mode cycle -CycleScale 3 -Duration 1500 -ReliableUDP -IdleHandoff -WinterDoors -WinterWindows -DebugConsole -Target armored -LootCatalog .\config\windows-smoke-20261015.json
```

Путь оригинала по умолчанию `G:\REsearch\Ring of Elysium-2022`; повторно исправная независимая runtime-копия переиспользуется. Вход через Training. В основном опыте оставьте клетку появления по умолчанию: восемь контрольных предметов лежат рядом именно с ней. Дождитесь завершения intro/появления управления. Планер выбран заранее.

Не добавляйте `-NativeEvacuation`: этот отдельный опыт пока требует `CycleScale1`. `Duration1500` ограничивает весь процесс25мин, включая вход; календарь матча при Scale3 около9мин28с. Без Scale остаётся быстрый календарь около189с.

Для ещё не проверенных вами комплектов — два отдельных коротких опыта, основной цикл повторять не нужно:

```powershell
.\run-roe-2022.cmd -Kit snowboard -Duration 600 -ReliableUDP -IdleHandoff
.\run-roe-2022.cmd -Kit climb -Duration 600 -ReliableUDP -IdleHandoff
```

W16-K2: snowboard — DE7/10,5бинтов и доска. W16-K3: climb — Citori2/10,5бинтов и трос. Способность на T должна соответствовать выбранному комплекту. Исходный XML задаёт предметы; полный начальный магазин — наша политика. Результаты и экспорт каждого опыта — отдельно.
