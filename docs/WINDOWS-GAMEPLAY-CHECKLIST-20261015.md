# Проверка Windows2022 после исправления стартового набора

В корне checkout:

```powershell
git pull --ff-only
.\run-roe-2022.cmd -Mode cycle -Duration 900 -ReliableUDP -IdleHandoff -WinterDoors
```

Игра: `G:\REsearch\Ring of Elysium-2022`. Запускается независимая runtime-копия; при готовой копии повторное копирование всех ресурсов не требуется. Войти через Training и дождаться окончания подготовки. Для дверей в этом контроле явно включён `-WinterDoors`.

В `runs/<номер>/launch-summary.json` должна быть `launcher_revision: 20261015-starter-v1`, `weapon_slots: 3` и `source_hashes`. Без этих полей новый код не подтверждён: журнал c6ada6 использовал два слота и прежний guard.

| Что сделать | Ожидаемое поведение |
|---|---|
|Выбрать сноуборд до начала матча|Desert Eagle7/10, пять бинтов, сноуборд, вместимость225|
|В отдельном запуске выбрать планер|Glock17/15, пять бинтов, планер, вместимость150|
|В отдельном запуске выбрать кирки|Citori2/10, пять бинтов, кирки, вместимость300|
|Один выстрел и R|DE7/9; Glock17/14; Citori2/9 после завершения R|
|Перетащить найденное оружие прямо в пустой второй слот|Оружие исчезает с земли и появляется в выбранном слоте|
|Перетащить ещё одно прямо в пустой третий слот|В инвентаре три оружия, предыдущие не заменяются|
|Перетаскиванием поменять два занятых слота|Оба экземпляра сохраняются; их патроны/обвесы не обнуляются|
|Выстрелить, выбросить и подобрать то же оружие|Сохраняется оставшийся магазин; патроны не создаются заново|
|Быстро выбирать разные доступные клетки до окончания подготовки|Маркер подтверждает выбранную клетку без постоянной паузы≈5с|
|Подойти к двери, F открыть/закрыть и пройти|Дверь меняет состояние; взаимодействие записывается в scene/events|

Жилет и шлем не выдаются исходным стартовым набором — их нужно подобрать. Определения/количество стартовых вещей взяты из `InitItem.xml`; полный начальный магазин и слот1 пока правило нашего peer. После каждого запуска передать **всю папку** `runs/<номер>` и коротко указать результат каждой проверенной строки. При задержке карты новый журнал сохраняет поля отклонённого запроса; сырые авторизационные пакеты для этого не нужны.

Proton подтвердил три комплекта, fire/R и manual drag вslot2/3. Новый Windows-повтор пока ожидается. Старый c6ada6 подтвердил стрельбу/перезарядку/drop/pickup; его отказы переноса и лимит2 не относятся к этому профилю.
