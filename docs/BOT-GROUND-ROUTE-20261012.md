Native309: настоящие W/D/A/S без прыжка записаны только как публичные координаты собственной сущности и single-application2A. Decoder2A140C56410;27decoder140C5A0E0. `ground_route_2022.py`: ограниченный граф2..128узлов/256рёбер, Dijkstra по трёхмерной длине, цели соединены только явно заданными рёбрами. Предел ребра10м/уклон1:1 — собственный критерий стенда. XY-область камня X371000..372050/Y543450..544650 задаёт исследователь; это не экспорт его точной коллизии. Пересекающее её ребро отклоняется даже при большом Z. Патруль идёт обратно по проверенным рёбрам, без прямого замыкания через камень. ActorFixture ground_route_file переопределяет стартовую позицию/профиль и маршрут.
