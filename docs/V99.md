# V99: сеть и Windows LAN

Источники: `research/builds/v99/hosting-route-20261006`, `docker-scene-20261006`, `windows-launcher-20261006`, `windows-lan-20261006`. Переносимый код находится в отдельном `ROE-LIVE/roe-server`, а не в этом контекстном репозитории.

## Проверенный сетевой путь

Для x64 EXE при базе `0x140000000`: sender `140d66f80`, dispatcher `140d676d0`, response360 `1412ac730`, connector `140ed170e`, native notify `140e84bb0`, transition `141727e50`, ammo store `141199238`. Эти адреса не относятся к 2022.

LWIP selector — `1430d4137`, endpoint — `14318cdc0`, port — `1430d83f8`. Sender+0xB8 отделяет локальную очередь от сети. В опытах эти поля менялись временно; штатные источники состояния ещё не восстановлены.

Настоящий UDP3366/AES4013 с собственным тестовым handshake подтверждён. Peer17 после выключения native adapter получил настоящие `11DA` fire, `49C` reload, `3B63` pickup. Ответы `4A0/49D/5FB/821/82B` дали HUD2/20 и 120 секунд без зарегистрированной network-failure. Peer19 после диагностических 320/341 получил все настройки, часы, инвентарь и лут по UDP; клиент двигался до (370671,271678,37765), итог HUD1/22. Запланированный результат 2/20 в 19 не достигнут: ранние действия не породили запросов. Поздний Docker/Proton опыт с Citori с земли прошёл отдельно.

## Windows 11

Launcher создаёт полную независимую копию около 13.6 ГиБ, проверяет SHA x64 EXE и наличие ресурсов. Требуется Python3.11+ x64. Он запускает локальное Python lobby, UDP bridge и собственный VEH bootstrap. Нужно ждать **105 секунд и `queue_enabled`**, затем проходить регион/персонажа и Training. До готовности объекта ранний `2F0` корректно даёт `scene_user_not_ready`. Backend VEH проверен; backend win32 в Proton давал ранний выход, причина неизвестна.

Пользователь сообщил об успешной ходьбе и стрельбе с Windows11. Переданный лог `20261006T222744-271983` показывает 320/341, карту 16007, 360, native_connected и server_ammo_applied magazine1. Сервер увидел источник 192.168.1.121:61661 и позднее состояние 2/7. Полного Windows events.json, снимков, cleanup и SHA после этого сеанса нет. Отдельные подбор и перезарядка не подтверждены этим фрагментом. Источник — `windows-lan-20261006/server-summary.json`; кольцевой журнал 2000 записей вытеснил ранние запросы.

## Host и ограничения

Путь InitServerModule `1438ca691/1438ca697` получил нулевой HMODULE в раннем опыте. Конструктор `140ed0d10` обнуляет owner+0x138. Это не доказанная ошибка LoadLibrary и не исключение всех других host-механизмов. Комплектный встроенный сервер с Generic* не найден.

Нет штатного login/создания сцены без bootstrap, серверного урона, зон, AI, транспорта, общей одежды/инвентаря и полной надёжности UDP при потерях, перестановках и compressed-unreliable. Более богатые механики 2022 нельзя приписывать этому peer.
