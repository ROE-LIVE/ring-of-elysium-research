# Происхождение локальной пары handshake

`candidate-001.key`:16байт sessionkey локального эмулятора. Исходное исследование ROE_SERVER/research/builds/2022/session-06-review/report.md: ключ найден по состоянию qapi (mode+0xB4,flag+0x7C,key+0x80,AEScontext+0xC0) и независимо проверен расшифровкой331DT/4DC, а также совпадением plaintext CK в четырёх соединениях. Это локальный опыт с фиксированными ответами эмулятора; постоянство для официальных пользователей/серверов не доказано.

`lobby-ck.bin`:32байта CK payload из прежнего `search/Ring-of-Elysium-Lobby-Emulator/LobbyEmulator/Logic/LobbyPreData.cs`, присваивание `a.Data`. В публичном игровом комплекте этот payload вынесен в файл. Это зашифрованное сообщение установки sessionkey, а не второй пароль. Полный CK packet имеет дополнительный framing, которого в32байтном файле нет.

Обе зависимости включены в ring-of-elysium-local по прямому указанию владельца для передачи локального стенда. Это узкое исключение; LoginKey, билеты, пароли, реальные данные аккаунтов и полный AUTH не публикуются. Значения в документации не приводятся. Случайно сгенерированный ключ не совместим с неизменённым CK.
