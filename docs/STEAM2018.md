Есть 45 активных нативных Generic* зависимостей: строка 115 — loot,320 — shrink,430 — start,459 — drops,461 — vehicles; предусмотрены роботы. Lua задаёт порядок вызовов, но не реализует физику/AI. ## Запуск

Отсутствовавший x86 ld-linux устранён. Старый WoW64 падал в Base RVA`0xb9751`; newWoW64 прошёл этот барьер. SLauncher без SteamAPI давал init failed. Диагностическая модель пяти Steam imports позволяет создать EXE, но сцена не достигнута: Warning(0,404,449). Win7 profile и другой SteamID этого не исправили. Ошибки TesSafe.sys/Wine сопутствуют отказу; точная причинность не доказана.

Главный запуск EXE RVA`30609fd` проходит Base RVA`2b738/26d1c` к виртуализированному `154fdce`. Второй поток Base`41bf00` ожидает через `41d9ed/41bf33`; назначение неизвестно. В выбранном снимке есть Base/BugTrace и нет FPSRpcs/ProtocalHandler. Замораживать поток по одному диапазону DLL не обосновано.

Windows run184905/200302 имели ранние проблемы запуска. Run201052-428915 с steam_appid.txt755790 создал дочерний Europa_Client37680. Пустое responsive окно не подтверждает игровой UI. Нет exit-code и доказанной причины завершения или BSOD. Пользователь сообщил о крашах Windows; сначала изучать существующие системные свидетельства, новый нативный запуск отдельно согласовать.

Для host нужен совместимый модуль InitServerModule/Generic* либо узкая трасса загрузки DLL/экспортов/XYGameServer.fcf/QsSvrGui/svrmgr.xml. `roe_thread_freezer.py` сам по себе не восстанавливает модуль; произвольная заморозка не обоснована.
