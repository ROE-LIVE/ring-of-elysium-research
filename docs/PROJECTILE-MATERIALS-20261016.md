## Найденный клиентский расчёт

Reflection `14052E8A0`, PC14052EC83/14052ECD2/14052ED26, связывает `mPenetrationModifier` с +0x38, `mDamageLostPercent` с +0x3C, `mPMAndDLPNoAverage` с +0x40. В `140FC3F20` материал ищется по ID (140FC43E0), поля читаются по140FC4404 и140FC47C1/47C6. Если no-average выключен, код может усреднять параметры текущих пересечённых материалов (140FC4800–4893); проверены пока только однородные Rock-границы.

Для положительных P и power и фактически выбранных параметров native ветка140FC4898–4966 соответствует:

```text
inverse = 1 / P
thickness2 = squared_distance(entry, exit)  # world cm
loss = max(0, E*D + inverse*3*max(0, 3/power*1.25)
              + thickness2*inverse/154.83839416503906)
E_next = E - loss
stop, если E_next < 1
```

Это запись подтверждённой ветки. Для P≈0/power≈0 в коде есть отдельные fallback; приведённая формула их не описывает. Запись E_next —140FC495A, проверка —140FC4962/4966. Последующее прохождение также ограничивают счётчик, дистанция и тип/флаги столкновения.

| Native012 | E / power | Толщина, см | Native loss / E_next |
| --- | --- | --- | --- |
| M4, Rock | 40 / 1,5 | 90,16392 | 139,740753 / −99,740753 |
| AK-47, Rock | 47 / 2,5 | 70,25916 | 88,365906 / −41,365906 |
| AK-47, край Rock | 47 / 2,5 | ≈2,27 | 17,594048 / 29,405952 |

P≈0,45/D≈0,16 прочитаны у настоящего Rock305 и совпали с XML. Расчёт double для первых двух строк отличается от native float менее0,000003. На тонком краю функция вернула0/продолжение вместо1/остановки; target hit после прохождения не получен, попадание сквозь камень по NPC не заявляется.

`BULLETCONFIGTABLE.XML` задаёт M4 power1,5, AK2,5/count3. Базовые `nDamage`400/470 и конструктор `140FC1820` с множителем0,1 были известны из опыта10.10; новизна16.10 — выполненная формула расхода на материале и контраст толщины. Поле bullet+1BC не отождествляется с authoritative HP. В первом trace label `bullet_enabled` для +1D0 был ошибочным:0 не мешает формуле, исправлено на `flag_1d0`.
