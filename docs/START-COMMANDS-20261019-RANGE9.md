# Две команды запуска2022

После `git pull` откройте PowerShell в корне run_roe_2022.

```powershell
.\training.cmd
```

Стрельбище: Training в лобби, клетка **12,26** (Sidera Lodoicea Ski Resort), дождаться подготовки. Рядом разложены25 поддерживаемых видов оружия,29 модулей (включая прицелы),7 типов патронов и8 вариантов брони/шлемов. Это весь реализованный набор эмулятора, не все определения оригинальной игры. Ряды идут по Y; для дальних предметов подойдите ближе (подбор до7,5м). Стартовая M4 и её патроны находятся в ближнем учебном наборе. M4/AK появляются пустыми: подберите соответствующие патроны и нажмите R. Боезапас конечный; предметы не возрождаются автоматически.

Девять бессмертных неподвижных моделей на юго-восток, примерно по азимуту120°. От исходной точки по горизонтали50,100,…450м; между соседями50м. Высота каждой взята из исходного рельефа. Порядок жилета и шлема: **0,1,2,3,0,1,2,3,0**. Для дистанции ориентируйтесь на обозначения T1..T9; числа относятся к исходной точке, после движения игрока не являются текущим дальномером. Ряд линейный: близкая мишень может перекрыть дальнюю; можно отойти в сторону и использовать прицел. Деревья/камни тоже могут мешать стрельбе.

Подписи: после загрузки Enter → вставьте полную строку из `runs\<текущий запуск>\client-debug-command.txt` → Enter. Появятся номер, дистанция, L0–L3, затем последний урон/часть/поглощение. Чтобы девять надписей не накладывались, показывается подробная подпись ближайшей к центру экрана цели; после попадания она3секунды закреплена на поражённой цели. Каждый hit восстанавливает HP и защиту цели, поэтому она не умирает и не даёт убийства. Баланс — явная учебная v3; исходная серверная формула не восстановлена. На дальнем краю действует также дальность самого оружия. Урон по разным типам NPC не сравнивать без одинакового оружия/части/дистанции.

Тир не запускает поздние события аирдропа и вертолёта. Он нужен для оружия/инвентаря/мишеней; эвакуация проверяется в game.

```powershell
.\game.cmd
```

Игровой профиль: Training в лобби → выбор клетки/комплекта → поиск лута → зоны → аирдроп → эвакуация. Календарь около31,5мин, каждый матч получает новый seed. Есть исходные точки лута и наши веса/RNG, две проверенные площадки вертолёта. Фиксированные19 учебных предметов пока также остаются у12,26. Для поиска ресурсного лута удобен квартал16,27. Команда не добавляет учебных NPC/бессмертных целей. Эвакуация: добраться к доступному тросу, один раз F и дождаться подъёма; повторное F может прервать действие. Включён учебный урон корпусу машин102/109 по таблице оружия: стрелять снаружи, в корпус, с расстояния до100м. Столкновения, колёса, топливо, урон пассажиру и падение игрока не восстановлены. Подробнее docs/recovery/car-table-20261019/report.md. Полноценный multiplayer и исходный host отсутствуют.

Обе команды рассчитаны на7200секунд процесса, чтобы таймер запуска не прерывал подготовку/повторный матч. Они запускают локальные службы и независимую runtime-копию. Исходный каталог не меняется; первый запуск может подготовить копию и зависимости. Закройте игру перед переключением профиля.

Путь по умолчанию `G:\REsearch\Ring of Elysium-2022`. Если другой:

```powershell
.\training.cmd -Client "D:\Games\Ring of Elysium-2022"
.\game.cmd -Client "D:\Games\Ring of Elysium-2022"
```

Параметры обеих команд хранятся **в одном файле `config/launch-profiles.json`**. Пользователю не нужно редактировать длинные строки: обновляйте репозиторий. Старый run-roe-2022.cmd сохранён для исследовательских профилей.
