# Расширенные записи попадания11DD, 16.10.2026

Клиент2022, корневой `Europa_Client.exe`, x64 SHA256 `2dca9b1e122e21363e14eeeb2372598c773205a907ed8d2b2d54a7229ad6ba18`. Исследование и живые проверки — независимый Proton runtime, loopback. Адреса не относятся к XVersion/V99/2018.

## Исправленная причина

Прежний ActorState/SharedCombat принимал только106байт11DD. Настоящий AK после прохождения тонкого края Rock305 прислал144байта: фиксированная часть104, countBE16=2 и две записи поверхности по19байт. Старый обработчик отбрасывал сообщение до проверки попадания. Теперь поддержаны оба установленных варианта записей; они журналируются и не создают дополнительный урон.

| Смещение / вариант | Wire-схема |
| --- | --- |
| 0..103 | Прежняя фиксированная часть; targetUID@4, part_id@62, bullet_id@88, ratio@92, pellet_index@100 |
| 104..105 | Число записей BE16, не больше30 |
| tag0 | `>BBBI3f`: tag0, два пока неприсвоенных u8, materialBE32, floatXYZ; всего19байт |
| tag1 | `>BQB`: tag1, unitUIDBE64, part_id; всего10байт |

Размер: `106 + 19*N0 + 10*N1`. В частности, 116байт для одной unit-записи, 135 для смешанной пары, 144 для двух surface. Native memory stride0x13 **не означает**19байт на wire для unit-варианта. Значение part_id в основной части: HEAD1/BODY2/LIMB3; поле83 — shooter_path_use_c.

## Первичные адреса

Decoder `140C3FE00`: count/предел30 в140C401C7..1D3, вызов union `140C40211→140C3F5A0`. Encoder `140C3FB70`, count140C3FD6B..87, union140C3FDC1→140C3F540. Surface encoder/decoder140C3F410/140C3F490; unit140BF3580/140BF35D0. Producer140FC54EF..54FE создаёт tag1 и переносит UID из result+0x28, part из+0x24.

Эмуляция выбранных native code pages подтвердила длины106/116/135/144 и отказ на count31/обрыве. Native допускает trailing bytes и неизвестный union-tag без тела; наш peer намеренно принимает только полностью разобранные известные варианты0/1. Неизвестные/оборванные записи, NaN/бесконечные координаты и хвост отвергаются до изменения HP/dedup. Это поддерживаемое подмножество, а не полная совместимость с любым native вводом.
