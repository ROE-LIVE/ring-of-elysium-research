## Что нужно сохранять между контейнерами

На постоянном диске — исходные клиенты, ROE_SERVER, ресурсы, малые fixtures, Proton/tools и независимые runtime/prefixes; отдельно roe-server для V99. В образе — системные и Python зависимости. Session-key2022 — отдельно с закрытыми правами, без чтения/публикации содержимого. Пустой volume поверх /opt/conda скрывает интерпретатор из image.

[Наблюдавшиеся пакеты](../catalog/environment/observed-system-packages.json) и [адресная проверка среды](../catalog/environment/observed-preflight.json) — снимки2026-10-07 после пересоздания контейнера. Пропуски GDB/компиляторов/Vulkan tool/x86-loader в том снимке не отменяют их применение в прежних опытах. Это не актуальная проверка нового образа и не полный lockfile.

Для сборки/пересоздания среды использовать jupyterROE. Для исследования конкретного билда — соответствующий отчёт и разрешённый опыт в исходном workspace. Описание полного переноса: [источники](SOURCES.md).
