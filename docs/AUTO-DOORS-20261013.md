## Реализация и запуск Windows

`DoorState` хранит состояния в одиночной сессии. Повтор запроса задаёт то же состояние, не переключает его снова; malformed/неизвестный ID/недопустимое состояние/дальний запрос отвергаются. При выходе из радиуса и возврате снимок повторяется; перенос игровой сессии сохраняет объект и сбрасывает только отметки отправки. Новый матч начинает исходные состояния. За heartbeat выдаётся максимум16записей. Общая комната нескольких игроков пока не поддержана.
