# NET09: общий наземный лут2022, 11.10.2026

Пара клиентов2022 на Iceland16010 движется и стреляет без обхода через транспорт. Введение общего реестра наземного лута позволило проверить подбор одного предмета двумя клиентами, выброс и подбор другим игроком. Общая сессия пока частична; NET09 остаётся ready40.

Проверено Proton, отдельные runtime-копии и префиксы в одном loopback namespace, без Docker. UID аккаунтов…2430/…2434. ПослеA3с native-позиции изменились на10.43/9.63м, удалённый аватар применил координаты второго клиента. Причина зависимости ввода от младших битов UID не установлена.

Один предмет содержит20 патронов12ga. У игроков исходно6/6. Два запроса пришли с разницей27мс: один получил20, второй — отказ; земля пуста на обоих клиентах, резерв6/26. Затем второй выбросил26, первый увидел и подобрал; стало32/0. Поздний холодный вход…2438 показал пустую землю и стартовые6 патронов. Это собственная серверная модель с фиксированным пресетом, не оригинальный генератор.

Исходники: `ROE_SERVER/server/directory/shared_loot_2022.py`, `game_endpoint_probe_2022.py`, `weapon_probe_2022.py`. Endpoint-флаг `--shared-ground-loot` выключен по умолчанию, требует weapon-config и отвергает loot-catalog/parcel-config. Комната хранит остаток/tombstone по(room_uid,index); обработка запроса и фиксация синхронны в одном event loop. Выбросы получают общий ground UID/index. Начальные instance UID оружия пока принадлежат области инвентаря аккаунта.

Первичные поля ground821/100B: UID+4, XYZ+29, definition+63, quantity+67, index+71; C2S3B63/33B и SC82B/8B. Native actor manager world+1EE8, remoteVTable14276d6e8. Не применять адреса кV99/2018.
