## 77 — DROP05

Опыты 179–185: старый шаблон аирдропа оставался неподвижным; исходное тело 117 байт активировало физику клиента. Отдельный опыт подтвердил активацию при изменении только байта +56 с 1 на 0. Назначение поля по потребителю ещё не установлено. Клиент вычисляет движение и контакт с поверхностью, отправляет `6549/73`. Диагностический сервер принимает движение только для явно разрешённой сущности, проверяет тик и границы перемещения, обновляет координаты подбора.

Это режим с доверием к координатам одного клиента, а не восстановленная серверная физика или генерация лута. Подбор после полёта, перенос состояния при переподключении и Windows остаются непроверенными. В опыте 185 игрок подошёл близко к контейнеру, но подтверждённого запроса подбора до таймаута не получено.

## 78 — DROP06

Подтверждён нативный текст «Airdrop supply has arrived». Пакет `04A6/26`, декодер `0x140C43040`; вторые XYZ в исходных записях нулевые. Трактовка их как конца траектории самолёта не доказана. Маркер карты не восстановлен.

Обычный запуск Windows сохраняет наземный контейнер и добавляет уведомление. Параметр `-NativeAirDrop` включает исходный шаблон падающего контейнера с высотой Z=301000. Проверки: 339 тестов исходного проекта и 290 тестов portable прошли; оба режима preflight и сборка .NET Release прошли. Сам запуск Windows требует проверки пользователем.

## 79 — EVAC03: следующая задача

В исходном захвате выделены 903 пакета `6575/73` одного эвакуационного вертолёта. Декодер `0x140C98C90` потребляет 73 байта. Траектория согласуется со скоростями 1440 см/с по горизонтали и 608 см/с при снижении. `6588/1` отмечает начало снижения, `6588/2` — достижение точки ожидания. Привязка группы 1 из PlaneBattleEnd к карте ещё не прослежена независимо. Собственный запуск этой траектории не выполнен; захват полного отлёта после ожидания отсутствует.

Следующий опыт: воспроизвести подтверждённые `6575` и `6588` на собственной сущности plane 6, проверить снижение, ожидание, трос и посадку; отлёт исследовать отдельно. Карточка: `python tools/recovery_task.py --task EVAC03 --preflight` из ROE_SERVER. План: [mechanics-2022.csv](recovery/mechanics-2022.csv).
