## Встроенный host

Во всех исследованных комплектах нет доказанного комплектного host. Нужен совместимый модуль с InitServerModule/ExecConsoleCmd/RegisterMapManager/RegisterGroupConfig/Generic* либо адресная трасса загрузчика с запрашиваемым именем/конфигом. В Steam ранний SDK пока блокирует старт. Строка UseListenServer, Lua или нулевой HMODULE не доказывают ни готовый host, ни окончательное отсутствие всех механизмов.

Для внешнего PACKET-DEFINITIONS нужен SHA исходного EXE; для античита — маршрут конкретного opcode и билд DLL; для второго байта extra header — writer. Прежние отрицательные опыты повторять только при новом материале или исправленной проверке.
