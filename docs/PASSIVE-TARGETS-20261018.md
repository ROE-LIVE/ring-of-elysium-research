# Десять пассивных мишеней и независимый лут — 18.10.2026

Основной2022 x64 0.2.989.0, корневой EXE SHA256 `2dca9b1e122e21363e14eeeb2372598c773205a907ed8d2b2d54a7229ad6ba18`, Iceland16010. Новый параметр Windows `-PracticeTargets 1..10` с `-Target plain|armored`; по умолчанию остаётся одна мишень. Совместное использование с активными `-Bots` не поддерживается.

## Реализация

`server/directory/target_roster_2022.py` клонирует проверенные565/BE7/MOVE шаблоны с отдельными UID, координатами, HP/бронёй и инвентарём. Для10мишеней UID `0x2040000800000..0x2040000800009`. Две фиксированные учебные строки X366300/366700, Y543650..544650; Z получен адресным чтением source `EU_ICELAND_4096/SERVERDATA/RIGIDTERRAINLINUX.PXBIN`. Координаты и результат reader находятся в `research/builds/2022/recovery/037-gun05/20261018T0920-target-roster/source-ground-points.json`; передаваемые точки — `config/practice-target-points.json` launcher. Это расстановка исследователя, не найденный исходный генератор NPC.

Endpoint маршрутизирует11DD и административный damage_npc по targetUID; попадание меняет только нужного actor. Повтор одного pellet не наносит второй урон; использование того же pellet для другой мишени отклоняется. Межцелевое пробитие одной пулей не исследовано, это ограничение стенда. Граната распределяется по зарегистрированным целям; новые гранатные пути проверены unit, native group grenade не проверен.

При смерти создаётся отдельный контейнер и переносятся текущие предметы/прочность брони. Исправлено наследование player starter_items: у NPC больше не появляются копии стартовых9mm, бинтов, способности и косметического профиля игрока. Для учебной пассивной цели явно задан запас12ga×6; оружие появляется в её трофеях только при явной экипировке шаблона. То же исправление внесено в одиночный BotController. TargetRoster и BotController переживают handoff и удаляются при завершении матча; сохранность controller проверена unit и Native007 loot/safe/handoff/death inventory; это не active combat AI, см. BOT-CONTROLLER-HANDOFF-20261018.md.
