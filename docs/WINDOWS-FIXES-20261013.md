# Исправление гардероба после Windows-прогона 3bbf48

Билд2022 x64 0.2.989.0, корневой Europa_Client.exe, SHA256 `2dca9b1e122e21363e14eeeb2372598c773205a907ed8d2b2d54a7229ad6ba18`. Оригинальные клиенты не менялись.

## Что исправлено

При замене одежды A→B сервер возвращал A в слот B. Меню сохраняло ссылку на исходный слот A; повторное сохранение и выбор A приводили к3E81/result1. Теперь снятая вещь возвращается в исходный слот каталога. Повтор точного выбора уже надетой вещи подтверждается без перемещения/дублирования. Чужая категория, неизвестная ссылка, неверное количество и own по-прежнему отклоняются. Старые сохранения сначала проверяются на полноту/уникальность, затем ненадетые вещи нормализуются по исходным слотам при загрузке.

Перенос оружия пока не объявлен исправленным: девять отказов Windows-прогона объединялись в pickup_fixture_or_distance. Теперь журнал отдельно показывает failed_checks (доступность, слот, target, флаги, дистанция) и публичные поля запроса. Ограничения подбора сохранены. DebugConsole дополнен init_equip_type1/2/3 по публичным HUD getters из INITITEMPANELLOGIC.LUA18–20; это диагностика выбора, не доказательство корректной маски способности.
