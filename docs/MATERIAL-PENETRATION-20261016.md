# Ограниченная проверка прострела по исходной геометрии

16.10.2026. Только корневой2022 x64 Europa_Client.exe0.2.989.0, SHA256 `2dca9b1e122e21363e14eeeb2372598c773205a907ed8d2b2d54a7229ad6ba18`, Iceland16010. Независимые runtime/Proton/loopback; собственный peer. Это opt-in опыт GUN06, не найденный оригинальный сервер.

## Изменение

Прежний `collision_mesh_file` считает выбранный mesh сплошной преградой. По умолчанию это поведение сохранено. Новый `material_penetration=true` разрешён только с одним явно выбранным однородным Rock305. Для M4/AK вычисляются две границы исходного mesh, толщина и остаток энергии по ветке клиента140FC4898–4966. ПараметрыP0,45/D0,16, энергия40/47 и power1,5/2,5 подтверждены XML и Native012; подробнее [материалы](PROJECTILE-MATERIALS-20261016.md).

Код: `collision_mesh_2022.py:boundary_hits`, `projectile_materials_2022.py`, `ActorState.validate_ray`. Рёбра с одинаковой точкой объединяются; два пересечения должны иметь входящую/выходящую ориентацию. Непарные/сложные границы, неизвестные оружие/материал и превышение пределов отклоняются. Толщина не берётся из присланных collision records. При отказе HP/броня/hit identity не меняются. При успехе остаётся прежний **учебный** урон100raw и штатный11EB: энергия не объявляется формулой HP.

## Доказательства

- Офлайн проигран настоящий144-байтный hit Native014. Вектор принятого выстрела восстановлен из числового экспорта, поэтому это не новый C2S-контроль. Исходные faces2066/2065,31,61152см, AK E47→15,13833; hit принят. Отдельные unit-контроли повторяют численные результаты Native012/017, проверяют непарную/перевёрнутую поверхность, неизвестный профиль, атомарный отказ и сохранение прежнего solid-режима.
- **Native023, настоящий AK:** через край камня пришёл11DD/count2. Исходная геометрия независимо дала12,44873см и E47→27,25588; HP1000→900, один11EB. Последующий открытый AK дал count0/HP800; открытый M4 — count0/HP700. Пересечения и фактическое применение связаны одним event `diagnostic_ray_material`.
- **Native024, настоящий M4 по толстой части:** hardware trace прочитал P/D/power1,5/E40, вход371203,6875/544654,4375/259270,90625 и выход371390,4375/544668,875/259326,5625. Native loss571,04480, E_after−531,04480, return1. Hit по мишени не пришёл. Это подтверждает остановку клиентской пули, **не отдельный отказ серверного hit**, поскольку клиент не прислал11DD.
- Попытки M4 по тонкому краю в023/024 не дали подтверждённого through-hit; открытые попадания и промахи не засчитаны как прострел. Новый native M4 through-control остаётся следующим опытом.

## Границы

Проверен один mesh/поза/один материал, не вся карта и не все стены. Нужны смешанные материалы, несколько объектов, точные count/distance/fallback и поведение около порогаE1. Проверка использует заявленный impact и прежние допуски origin/направления; независимый расчёт spread/баллистической траектории, доверенный origin и lag compensation не восстановлены. На остром краю малое отклонение impact сильно меняет толщину. Это не полная защита от поддельного попадания.

Обычный Windows-профиль не включает этот режим и не нуждается в исходном SFC выбранного камня. Новый код требует лишь stdlib; оригинальный ресурс остаётся локальным и читается ограниченным блоком по SHA.
