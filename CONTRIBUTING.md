# Передача результатов

Для изменения игрового поведения отправляйте правку в ring-of-elysium-local; для нового факта, структуры пакета или плана — сюда. Взаимосвязанные PR указывают commit второго репозитория.

Минимальный результат: ID задачи, билд/SHA/база, версия инструментов, начальные условия, воспроизведение, ожидание/факт, первичный источник/адрес/offset, положительный и отрицательный контроль, ограничения, следующий опыт. Пользовательское наблюдение не маркировать собственным native-контролем.

CSV имеет UTF-8 BOM и разделитель `;`; стабильные ID/sequence сохраняются. Проверка: `python -B tools/tasks.py --validate`, тесты: `python -B -m unittest discover -s tests -v`. Проверка не удостоверяет отсутствующие внешние доказательства и не повышает оценки.

Не добавляйте клиент, ресурсы, извлечённый игровой Lua целиком, ключи, пароли, исходный AUTH и полные дампы. Для shared отчёта подходят выбранные обезличенные игровые события. Перед новым экспериментом проверьте разрешение на запуск и локальные правила стенда.

Исключение для публикации: только фиксированные private/candidate-001.key16 и private/lobby-ck.bin32 в ring-of-elysium-local разрешены владельцем. Любые остальные private и учётные данные не добавлять.
