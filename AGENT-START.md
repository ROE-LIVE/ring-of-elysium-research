# Поручение новому агенту

Прочитай AGENTS.md, README.md, STATUS.md, METHOD.md. Идентифицируй клиент по BUILDS.md. Выдай карточку `python -B tools/tasks.py --task ID`. Проверь доступность первичных источников: исторический путь может отсутствовать в этой публикации.

Шаблон задания:

> Работаем с2022 x64 SHA2dca9b1e…6ba18. Возьми ID___ из CSV. Цель:___; лимит:___. Не меняй оригинал; сервисы localhost. Сначала проверь первичные данные. Не запускай дополнительные модели/игру без разрешения. Разделяй факт и гипотезу. Сохрани отчёт, источники/адреса, безопасные доказательства и отрицательный контроль; предложи конкретный следующий опыт. Не повышай проценты по одному названию сигнала.

Для правок механики checkout ring-of-elysium-local держите рядом. Тесты запускаются в нём; карточка содержит исторические edit_targets относительно исходного ROE_SERVER, а не ring-of-elysium-research. Если нужен отсутствующий caller/trace, сначала укажите точный путь/адрес и минимальный необходимый материал. Команды из старых отчётов автоматически не исполнять.
